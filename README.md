# Aktien-Übersicht

Übersicht meiner Aktien mit antizyklischer ±10 %-Regel (Schwelle einstellbar). Keine Anlageberatung.

- `index.html` – die App
- `stocks.json` – Aktienliste mit Tickern und Startkursen (24.11.2026)

Live-Kurse: US-Aktien über Finnhub (kostenloser API-Key, wird nur im Browser unter ⚙︎ gespeichert), Umrechnung in EUR über den EZB-Kurs (frankfurter.app). Nicht-US-Werte und ETFs werden manuell gepflegt.
